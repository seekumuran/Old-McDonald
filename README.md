Old-McDonald is an autonomous agricultural drone system that combines UAV hardware, onboard sensing, computer vision, geospatial intelligence, and reinforcement-learning-based flight planning to autonomously survey farmland and transform aerial imagery into actionable agricultural data. The system captures and processes aerial imagery to map field boundaries, identify crop regions and detect spatial anomalies, while an adaptive flight-planning layer learns to balance coverage, battery consumption, and information value instead of relying solely on fixed waypoint missions. The complete pipeline spans autonomous flight, sensor fusion, edge AI, computer vision, remote sensing, geospatial mapping, reinforcement learning, and agricultural data science, connecting a physical drone to an intelligent agricultural mapping and monitoring platform.
